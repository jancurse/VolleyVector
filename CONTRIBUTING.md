# Contributing

VolleyVector is a small personal project. Issues are welcome (bug reports, ideas, questions). Pull requests are welcome, but we recommend opening an issue and discussing it first.

For a security bug, please follow the [security policy](SECURITY.md) instead of opening a public issue.

## Building and running

See the [developer guide](docs/development.md) for setup, development and deployment, and [docs/architecture.md](docs/architecture.md) for how the code fits together.

## Conventions

- Open a PR rather than pushing to `main`.
- Squash-merge with a clear commit message (e.g. the PR description).
