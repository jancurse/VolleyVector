# Auto-stats scratch code

Experiment code for automatic stats detection. It is not part of the app: the build, the linters and the tests ignore this folder.

- The project's docs are in [../docs/auto-stats/](../docs/auto-stats/README.md).
- The data is outside the repo, at `../../data/` from here. See [data.md](../docs/auto-stats/data.md).
- Keep each task's scripts in a folder named after the task, and shared tools at the top level.
