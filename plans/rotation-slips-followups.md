# Rotation slips: follow-ups

Changes the user asked for after trying the branch. All are built; see the handover.

## Roster

- **Bulk add.** Import players from a pasted or uploaded format (e.g. CSV: number, name, main, secondary), so an agent can turn a team spreadsheet into it. Add-only, with a preview and errors (such as a duplicate number) before saving.

- **Player access.** Players can view the roster read-only. Today only the coach-only gear and **Manage team…** lead to it.

## Game page

- **Card width.** The game card is too wide and hard to read.
- **Squad.** Show the squad as a table (number, name, position, alternative positions), not tag chips. Pick players through a multi-select picker instead of always listing the whole roster.
- **Per-game overrides.** Change a player's number or positions for one game only, without touching the roster. Rare, so it sits in the squad picker rather than the main view.

## Lineup editor

- **Edit on the slip.** There is no good view, only edit and print. The editor should look like the rotation slip and be edited in place.
- **Rotate buttons.** Place them next to the rotation, not far away.
- **Possible subs.** Rename "Planned subs" to "Possible subs". Behaviour stays.
- **Eligible subs only.** The sub picker must offer only players not yet selected. It currently still lists other starters.
- **Player picker.** Make picking easier and clearly show who is not yet selected. With the 5-1 option on, a zone lists players whose main position fits first, then those whose secondary fits, visually distinguished. Everyone else is hidden behind a "show all" option. Make it well designed and easy to use.
- **5-1 option.** A per-lineup option, on by default, that drives the picker ordering above.

## Overview slip

- One slip, above the lineups, that shows every squad player at their position (e.g. all setters in the setter's zone), with numbers and names and the same rotate controls.
- Optional in the print.

## Player view

- The read-only game page works but looks poor: one small, too-wide slip inside a huge full-width card.
- Players get no rotate controls. They should be able to rotate through the lineup.
- Possible subs look odd: each incoming player renders as a tag.

## Print

- The PDF looks poor and has no left margin. Redesign it to look modern and appealing.
